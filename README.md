# 📦 Store Manager

Store Manager is an offline-first mobile application built for shop owners and small businesses to manage inventory, billing, expenses, profit tracking, and multiple stores from a single device.

The app works completely offline using SQLite and local storage, making it fast, secure, and reliable even without internet connectivity.

---

# ✨ Features

- 🏪 Multi-store management
- 📦 Product & category management
- 🧾 Billing & PDF invoice generation
- 📅 Financial calendar with profit/loss tracking
- 💰 Expense & sales management
- 🔍 Barcode scanning & smart search
- 💾 Backup & restore system
- 🔒 PIN lock & local data privacy
- 📊 Daily, monthly & yearly reports
- 📱 Clean and responsive mobile UI
